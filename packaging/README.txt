NEKO AI: QUICK START
====================

1. Start it
   Windows: double-click neko-ai.exe
   Mac:     double-click neko-ai (the first time: right-click it → Open → Open,
            because the app isn't signed by Apple)
   Linux:   run ./neko-ai in a terminal

   A window opens showing a cat and a SETUP CODE, and your browser opens
   http://localhost:8080. If the browser doesn't open, go to that address
   yourself.

   Keep that window open while you use Neko AI. Closing it stops the app.

2. Create your account
   On first start, choose a username and password and type the setup code
   from the window. You become the admin.

3. No API key yet? That's fine.
   Everything works except chatting with an AI: themes (the paw/bolt switch),
   light/dark, settings, memory, your file library.
   When you have a key: Settings → Providers → Add provider, pick OpenAI,
   Anthropic, Gemini, OpenRouter, Groq... and paste it. For free local models
   install Ollama and pick "Ollama (local)" (no key needed).

4. Use it on your phone
   Phone on the same Wi-Fi: scan the QR code shown in the window, or see
   Settings → Devices. On Windows, click "Allow" if the firewall asks.

Your chats and keys are stored in the "data" folder next to the program.
Back it up to keep them. Nothing is sent anywhere except to the AI provider
you choose.

Windows "Windows protected your PC" message: click "More info" → "Run anyway".
